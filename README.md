# 초록장바구니 버전3

PC에서도 장바구니 바로가기 버튼이 표시되며, 사이트 이름과 제목에 버전3을 표시합니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다.
자동 저장을 일관되게 사용하려면 이 폴더에서 `python -m http.server 8080`을 실행한 후 `http://localhost:8080`에 접속하세요.

## 파일

- `index.html`: 화면 구조
- `style.css`: 화면 디자인
- `app.js`: 검색·인증 설명·장바구니 동작
- `ORIGINAL_README.md`: 해당 시점의 원본 프로젝트 설명(원래 폴더 경로 기준)
